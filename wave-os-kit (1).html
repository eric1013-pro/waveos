⚡ WAVE OS 3.0 // STANDALONE UI ENGINE

Cryo-Blade Glass & Smooth Button UI Kit

홈페이지의 복잡한 콘텐츠를 모두 덜어내고, 글래스모피즘 표면 · 스페큘러 버튼 · 물리 스프링(glassDrag)만 순수 추출해 고도화한 모듈입니다.

← 메인 홈으로

01. Tactile Glass & Cryo-Blade Buttons

커서를 따라 표면 광원과 1px 크리스탈 림 라이트가 흐르고, 클릭·터치 시 부드러운 스프링 탄성(scale 0.97)과 파동 리플이 작동합니다. data-wos-async 버튼은 스피너 → 체크 드로잉으로 부드럽게 모핑됩니다.

02. Smooth Spring Segmented Control

클릭뿐 아니라 좌우로 드래그(glassDrag)하면 물방울처럼 늘어나는 관성 필(Pill) 인디케이터와 팝오버 메뉴입니다. 키보드 ←/→ 도 지원합니다.

03. Fluid Glass Switch & Precision Slider

드래그 중 노브가 투명한 리퀴드 글래스로 변형되며 부드럽게 따라오는 스위치와 정밀 슬라이더입니다.

Cryo-Mint Backlight Boost
Specular Refraction Intensity 65%

04. Frosted Input & Smooth Glass Accordion

포커스 림 글로우 인풋과 CSS Grid 0fr → 1fr 스프링 높이 전환으로 끊김 없이 열리는 글래스 아코디언입니다.

✦ SPECULAR 1PX RIM 45° CHAMFER
카드가 움직이지 않아도 커서 위치(--mx, --my)를 따라 1px 테두리만 보석처럼 반사되어 클릭 정확도와 고급스러움을 동시에 지킵니다.
세그먼트·탭 이동 시 거리와 드래그 속도에 비례해 물방울처럼 부드럽게 늘어나며 착지합니다.

05. Co-Linear Floating Glass Dock & Morphing Search Bar

좌측 탭바와 우측 검색 버튼이 1px의 어긋남 없이 수평 일직선(64px 고정)을 유지하며, 우측 돋보기 클릭 시 탭바가 접히고 검색창이 전체 폭으로 부드럽게 확장됩니다.

06. Notifications · Feedback

토스트 · 푸시 배너 · 인라인 · 모달 · 시트를 하나의 알림 시스템으로 묶었어요. 방식과 종류를 고르고 보내기를 눌러 보세요. 배너와 토스트(기록 옵션)는 알림 센터(벨)에 쌓이고, 아래 코드가 그대로 API 호출이에요.

12. Design Tokens · Quick Start · API

        
      

      
모든 색·반경·곡선은 --wos-* 토큰입니다. 키트 CSS는 @layer wos 안에 있어 다른 CSS와 충돌하지 않고, 값을 바꾸려면 :root 에서 토큰만 덮어쓰면 됩니다. 아래 칩은 현재 테마·액센트가 실시간으로 반영됩니다.

      

        
--wos-bg

        
--wos-fg

        
--wos-glass-bg

        
--wos-glass-border-strong

        
--wos-cryo-ice

        
--wos-cryo-mint

        
--wos-cobalt

        
--wos-gradient-primary

        
--wos-gradient-surface

        
--wos-r-pill / xl / lg / md / sm

        
--wos-a1…a6-rgb (accent)

        
--wos-spring-snappy / smooth / fluid

      

      
<!-- 1) 올인원 복사한 <style> / <script> 를 페이지에 붙여넣기 -->
<button class="wos-btn wos-btn-primary">Hello WAVE</button>

<div class="wos-card wos-chamfer" style="padding:20px">Glass Card</div>

<button class="wos-btn" data-wos-open="my-modal">Open</button>
<script>
  WaveOSUI.toast('Ready!', { type: 'success' });
  WaveOSUI.setAccent('violet');
</script>

      

        

          
API / 속성설명

          
            
WaveOSUI.toast(msg, {type,title,duration,icon,action})토스트 표시 (success · info · warn · error). duration:0 은 고정, action:{label,onClick} 은 버튼, 옆으로 쓸어서 닫기 지원. 반환된 요소의 .dismiss() 로 직접 닫기

            
WaveOSUI.open(id) / close(id)모달·시트 열기/닫기 (data-wos-open, data-wos-close 로도 가능)

            
WaveOSUI.setAccent(name, el?)cryo · violet · rose · amber · emerald, 파동 전환

            
WaveOSUI.getSettings() · setSettings(obj) · resetSettings()디자인 설정 전체(테마·액센트·유리/탭바 투명도·블러·모서리·모션·렌즈·햅틱)를 JSON 으로 읽고/적용/초기화. 앱 간 공유용

            
--wos-dock-opacity · --wos-dock-filter · --wos-glass-alpha · --wos-r-scale · data-motion설정이 조절하는 CSS 변수/속성 (직접 지정해도 됨)

            
WaveOSUI.notice({style:'toast'|'banner'|'inline', type, title, message, actions, duration, record, target})토스트·배너·인라인을 하나의 진입점으로 호출 (섹션 06 스튜디오가 이 코드를 그대로 생성해 줘요). 인라인은 WaveOSUI.alertBox('#target', {type, title, text, actions, closable})

            
WaveOSUI.notify({title, body, app, time, type, icon, actions, duration, tag, onClick})위에서 내려오는 푸시 배너. 최대 3장 겹쳐 쌓이고 위로 쓸어 닫기·호버 시 일시정지, 같은 tag 는 교체됩니다. 반환 요소의 .dismiss()

            
WaveOSUI.openNotificationCenter() · closeNotificationCenter() · notifications.{list, unread, markAllRead, clear}알림 센터. notify() 로 보낸 알림이 자동으로 쌓이고(최대 60개, 기기에 저장), 벨 버튼([data-wos-bell])에 읽지 않은 개수 배지가 붙어요. 항목은 옆으로 밀어 읽음·삭제, 센터가 열려 있으면 배너 대신 목록에 바로 반영. record:false 로 기록 제외, banner:false 로 배너 없이 기록만

            
WaveOSUI.contextMenu(x, y, items)컨텍스트 메뉴. items: [{label, icon, hint, tone:'danger', disabled, divider, onClick}]. 닫기 함수를 반환

            
[data-wos-swipe] · .wos-swipe-item · wos-swipe-action 이벤트 · WaveOSUI.swipeRemove(item)스와이프 액션 리스트. detail.action 으로 액션을 받고, swipeRemove 는 접히며 제거하고 restore() 를 반환 (실행 취소용). 행을 길게 누르거나 우클릭하면 같은 액션이 컨텍스트 메뉴로 열려요

            
.wos-alert[data-type] · [data-wos-alert-close]본문 안 알림 박스 (info · success · warn · error), 닫기 버튼은 접히며 사라짐

            
--wos-font-body · --wos-font-display · --wos-font-ko · --wos-font-ui · .wos-logo-word | -studio | -markTHRE3RIC 브랜드 글꼴·로고. 영문·숫자는 THRE3RIC Sans(글자·숫자와 & - . 만 제대로 그려져서 나머지 기호는 한글 글꼴이 대신 그려요), 한글은 굴림체 → 굴림 → 고딕 순서(Windows 외 기기는 나눔고딕 웹폰트). 코드는 고정폭. 글꼴·로고는 style#wos-brand 에 들어 있어 코어 CSS 복사에는 포함되지 않아요. 설정의 '글꼴'(html[data-font="plain"])로 끌 수 있어요

            
WaveOSUI.setLens('deep' | 'classic')다크 모드 전용 렌즈 톤. 기본은 deep, 예전 밝은 유리 톤은 classic (html[data-lens="classic"])

            
data-peek · data-peek-kicker (탭 버튼)탭을 길게 누를 때 뜨는 미리보기 문구. 없으면 data-goto 섹션의 제목·설명을 사용

            
WaveOSUI.toggleTheme(el?)다크/라이트 파동 전환 (선택 저장)

            
WaveOSUI.haptic(ms | [..]) · setHaptics(bool)진동 피드백 직접 호출 / 켜고 끄기

            
WaveOSUI.glassDrag(el, ind, n, opts)세그먼트·탭·스위치용 물리 드래그 엔진

            
data-wos-tip · data-wos-tip-pos툴팁 텍스트 / 위치(top·bottom)

            
WaveOSUI.morphButton(btn, ms?) · data-wos-async버튼을 스피너 → 체크 드로잉 완료 상태로 부드럽게 모핑

            
data-wos-acc (.wos-acc)0fr → 1fr 스프링 높이 전환 글래스 아코디언

            
data-wos-autogrow · data-wos-counttextarea 자동 높이 / 글자 수 카운터([data-wos-counter])

            
data-wos-check-all · data-wos-check-group전체 선택 체크박스 + indeterminate 자동 처리
