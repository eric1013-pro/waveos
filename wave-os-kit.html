Cryo-Blade Glass & Smooth Button UI Kit

홈페이지의 복잡한 콘텐츠를 모두 덜어내고, 글래스모피즘 표면 · 스페큘러 버튼 · 물리 스프링(glassDrag)만 순수 추출해 고도화한 모듈입니다.

← 메인 홈으로

01. Tactile Glass & Cryo-Blade Buttons

마우스를 올리면 커서 위치를 따라 마이크로 스페큘러 광원이 흐르고, 클릭·터치 시 부드러운 스프링 탄성(scale 0.955)과 파동 리플이 작동합니다. 터치 기기에서는 눌렀을 때만 반응해 "고정된 호버" 현상이 없습니다.

02. Smooth Spring Segmented Control

클릭뿐 아니라 좌우로 드래그(glassDrag)하면 물방울처럼 늘어나는 관성 필(Pill) 인디케이터와 팝오버 메뉴입니다. 키보드 ←/→ 도 지원합니다.

03. Fluid Glass Switch & Precision Slider

드래그 중 노브가 투명한 리퀴드 글래스로 변형되며 부드럽게 따라오는 스위치와 정밀 슬라이더입니다.

04. Frosted Input & Micro-Specular Surface

포커스 시 은은한 시안 림 글로우가 퍼지는 글래스 인풋과 뱃지 조합입니다.

✦ SPECULAR 1PX 45° CHAMFER

05. Co-Linear Floating Glass Dock & Morphing Search Bar

좌측 탭바와 우측 검색 버튼이 1px의 어긋남 없이 수평 일직선(54px / 축소 시 46px)을 유지하며, 우측 돋보기 클릭 시 탭바가 접히고 검색창이 전체 폭으로 부드럽게 확장됩니다.

06. Toast · Modal · Bottom Sheet

토스트는 쌓이고, 호버하면 타이머가 멈추며, 탭하면 닫힙니다. 모달·시트는 WaveOSUI.open('id') 또는 data-wos-open 으로 엽니다.

07. Accent Color Switcher

모든 컴포넌트의 광원·테두리·그라디언트가 data-accent 하나로 바뀝니다. 선택한 색은 기억되고, 전환은 파동 효과로 퍼집니다.

Haptic Feedback 스냅·토글·알림 때 짧게 진동합니다 (Android 등)

08. Tooltip · Progress · Skeleton

툴팁은 data-wos-tip 속성만 달면 됩니다(마우스 호버·키보드 포커스, 화면 가장자리에서는 자동으로 위치 보정). 스켈레톤은 로딩 중 자리 표시자입니다.

09. Checkbox · Radio

진짜 <input> 을 그대로 쓰기 때문에 키보드·스크린리더·폼 전송이 모두 네이티브로 동작합니다. 체크 표시는 선이 그려지듯 나타나고, "전체 선택"은 일부만 선택되면 자동으로 indeterminate 가 됩니다.

10. Input · Select · Textarea

필드별 라벨·힌트·에러 상태를 지원합니다. 제출 시 잘못된 칸은 흔들리며(shake) 첫 오류 칸으로 포커스가 이동하고, 텍스트 영역은 입력에 맞춰 자동으로 늘어납니다.

11. Design Tokens · Quick Start · API

모든 색·반경·곡선은 --wos-* 토큰입니다. 키트 CSS는 @layer wos 안에 있어 다른 CSS와 충돌하지 않고, 값을 바꾸려면 :root 에서 토큰만 덮어쓰면 됩니다. 아래 칩은 현재 테마·액센트가 실시간으로 반영됩니다.

--wos-bg
--wos-fg
--wos-glass-bg
--wos-glass-border-strong
--wos-cryo-ice
--wos-cryo-mint
--wos-cobalt
--wos-gradient-primary
--wos-gradient-surface
--wos-r-pill / xl / lg / md / sm
--wos-a1…a6-rgb (accent)
--wos-spring-snappy / smooth / fluid
<!-- 1) 올인원 복사한 <style> / <script> 를 페이지에 붙여넣기 -->
<button class="wos-btn wos-btn-primary">Hello WAVE</button>

<div class="wos-card wos-chamfer" style="padding:20px">Glass Card</div>

<button class="wos-btn" data-wos-open="my-modal">Open</button>
<script>
  WaveOSUI.toast('Ready!', { type: 'success' });
  WaveOSUI.setAccent('violet');
</script>
API / 속성설명
WaveOSUI.toast(msg, {type,duration,icon})토스트 표시 (success · info · warn · error)
WaveOSUI.open(id) / close(id)모달·시트 열기/닫기 (data-wos-open, data-wos-close 로도 가능)
WaveOSUI.setAccent(name, el?)cryo · violet · rose · amber · emerald, 파동 전환
WaveOSUI.toggleTheme(el?)다크/라이트 파동 전환 (선택 저장)
WaveOSUI.haptic(ms | [..]) · setHaptics(bool)진동 피드백 직접 호출 / 켜고 끄기
WaveOSUI.glassDrag(el, ind, n, opts)세그먼트·탭·스위치용 물리 드래그 엔진
data-wos-tip · data-wos-tip-pos툴팁 텍스트 / 위치(top·bottom)
data-wos-autocompact탭바(.wos-tabwrap)가 스크롤 방향에 따라 자동 축소/복원
data-wos-autogrow · data-wos-counttextarea 자동 높이 / 글자 수 카운터([data-wos-counter])
data-wos-check-all · data-wos-check-group전체 선택 체크박스 + indeterminate 자동 처리

변경 사항을 적용할까요?

글래스 모달은 바깥 영역 클릭, ESC, 닫기 버튼으로 닫힙니다. 열려 있는 동안 포커스는 모달 안에 머물고, 닫으면 원래 버튼으로 돌아갑니다.
